# House Price Prediction

## Project Overview

This project uses machine learning to predict house sale prices based on property features from the Ames Housing dataset.

## Objectives

* Explore and understand the housing dataset.
* Handle missing values and preprocess numerical and categorical features.
* Train and evaluate multiple machine learning regression models.
* Compare model performance and identify the best-performing model.

## Dataset

* Dataset: Ames Housing
* Records: 1,460
* Features: 80 input features
* Target Variable: `SalePrice`

## Machine Learning Models

* Linear Regression
* Random Forest Regressor
* Gradient Boosting Regressor

## Evaluation Metrics

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R-squared (R²)

## Best-Performing Model

Gradient Boosting achieved the best performance among the evaluated models, with an R² score of approximately 0.905.

## Tools and Technologies

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## Project File

`House Price Prediction.ipynb`

## Conclusion

This project demonstrates how machine learning regression techniques can be used to estimate house prices. Multiple models were evaluated, and Gradient Boosting performed best among the models tested.
